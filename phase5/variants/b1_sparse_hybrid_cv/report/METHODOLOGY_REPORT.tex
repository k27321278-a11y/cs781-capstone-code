\section*{Research question}
Check whether the strong sparse hybrid depended too much on one calibration split's fitted thresholds. The cross-validation route limits optimistic threshold fitting without using official dev labels for selection.
\section*{Architecture and mechanism}
The same 0.9 sparse/0.1 B1 blend is evaluated with five-fold cross-validation inside the official-train calibration subset. Class thresholds shrink toward a global prior according to support; the final thresholds are refit on all calibration rows.

The report records calibration CV macro-F1 0.4282, official-dev macro-F1 0.3933, and Codabench 0.3944. The latter is effectively tied with the fixed hybrid and does not establish a hidden-score gain.
\section*{Limitations and next check}
Five-fold calibration still has variance for rare labels; selection is not a substitute for a larger independent development set. Local, pilot, and hidden metrics are deliberately kept distinct. A single scored run does not establish a causal architecture effect or statistical significance.
