# Phase 4: Court Judgment Prediction

Start with the [13-package model index](model_packages/README.md). It distinguishes trained models from prediction-level ensembles, official-dev metrics from the user-supplied Codabench screenshot, and executed Kaggle notebooks from later explanatory companions.

The original Phase 4 code snapshots are organized under `shared_runner/`, `individual_model_notebooks/`, `kaggle_orchestrator/`, `b1_study/`, and `ensembles/`. Each package also contains the relevant source and compact run records. Downloadable per-model and all-model ZIPs are under [packages/phase4](../packages/phase4/).
