# CS781 L-NER Implementation Plan

> Execute inline with superpowers:executing-plans. The user authorized implementation and GPU1 launch of the previously proposed four experiments.

**Goal:** Train four NER adaptations from our saved Phase 1 checkpoints, export strict-span prediction ZIPs after each stage, and automatically download verified outputs.

**Architecture:** Character-aligned BIO classification uses contextual representations from each full pretrained backbone and a small bidirectional character head. LoRMA+ and LoRA are applied to projection layers; C1 is fully fine-tuned; A0 learns supervised labels plus cached B1 teacher distributions on the same character windows. A0 is slightly smaller than B1, not a new architectural family.

**Tech Stack:** Python, existing PyTorch environment, NumPy, our own BPE, original A0 tokenizer, standard-library ZIP/SHA/SSH orchestration.

**Spec:** ../specs/2026-10-11-lner-design.md

## Global constraints

Use exact official documents and labels, preserve original character offsets, document actual hardware, and never modify pretrained checkpoints. Use physical GPU1 only; preserve unrelated jobs. Export ZIPs with only root prediction.json. Validation documents never enter training or teacher-target generation.

## Tasks

- [ ] 1. Data: Unicode byte offsets, character BIO labels, fixed document split, overlapping shared windows and exact-span macro scoring. Test Unicode, boundaries, coverage, invalid IDs and duplicate spans.
- [ ] 2. Models: strict checkpoint/tokenizer load, full backbone representation adapters, LoRA and LoRMA+ linear wrappers, character head. Test identity initialization, documented multiplicative equation and gradients; real checkpoint finite forward/backward gate.
- [ ] 3. Trainer: finite mixed-precision updates, validation early stopping, atomic resumable saves, per-epoch status, complete-document decoding, official evaluator invocation and ZIP/hash verification. Test tiny end-to-end run and resume.
- [ ] 4. Queue: stages LegalSpan/LORMA, B1/LoRA, C1/full, A0/KD; failure isolation, process lock, teacher cache and one ZIP per stage. Local downloader catches up after disconnect and validates official IDs and hashes.
- [ ] 5. Launch: recheck GPU1/process identities, run preflight, start detached queue, verify loss/gradients and live status, start downloader, preserve monitor commands and handoff.

## Review focus

Unicode characters split across byte tokens; chunk edge truncation of entities; tokenizer/checkpoint mismatches; interrupted atomic saves/downloads; teacher leakage into held-out validation. Concrete tests and explicit assertions cover each.
