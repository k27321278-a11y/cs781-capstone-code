\noindent\textbf{Status.} Post-run methodology reconstruction grounded in archived source and reports. This document is not an executed historical notebook.\par
\section*{Research question}
Test whether adapting the full in-house Phase 1 A0 language model improves case matching beyond lexical overlap. The full model has about 110.3 million trainable parameters in the saved GPU report, much more than the partial or LoRMA branches.
\section*{Architecture and mechanism}
Four evenly spaced 256-token windows encode each query and candidate. The model mean-pools hidden states within each window and applies late max interaction across windows; supervised hard negatives come from the lexical retriever.

\section*{Limitations and next check}
A score tie on one hidden evaluation does not show the ensemble and full model made identical predictions. Local, pilot, and hidden metrics are deliberately kept distinct. A single scored run does not establish a causal architecture effect or statistical significance.
