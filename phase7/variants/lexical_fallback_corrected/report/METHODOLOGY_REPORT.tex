\section*{Research question}
Retain a simple valid submission path if the neural scorer fails to load. The fallback uses no adapted retrieval checkpoint, so it is a useful control against the more complex neural systems.
\section*{Architecture and mechanism}
Corrected lexical ranking excludes the query itself, checks pool membership and uniqueness, and emits exactly seven candidate IDs.

\section*{Limitations and next check}
It does not demonstrate that lexical matching understands legal entailment or precedent relevance. Local, pilot, and hidden metrics are deliberately kept distinct. A single scored run does not establish a causal architecture effect or statistical significance.
