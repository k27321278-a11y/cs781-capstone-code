\noindent\textbf{Status.} Post-run methodology reconstruction grounded in archived source and reports. This document is not an executed historical notebook.\par
\section*{Research question}
Reduce trainable capacity while keeping much of A0's learned legal representation fixed. The GPU report lists about 28.5 million trainable parameters, so this is a capacity comparison against the full 110.3 million route.
\section*{Architecture and mechanism}
The same four-window, mean-pool and late-interaction retrieval path is trained with a subset of Phase 1 parameters unfrozen.

\section*{Limitations and next check}
The partial tuning boundary is code-defined; do not infer that every layer was equally adapted. Local, pilot, and hidden metrics are deliberately kept distinct. A single scored run does not establish a causal architecture effect or statistical significance.
