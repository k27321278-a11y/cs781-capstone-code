\section*{Research question}
Establish a no-neural retrieval floor before spending T4 time on adaptation. This is a retrieval baseline and fallback, not a Phase 1 neural architecture.
\section*{Architecture and mechanism}
TF-IDF document features rank candidates by lexical similarity and emit seven IDs per query. The initial submission predates the later self-match correction.

\section*{Limitations and next check}
The historical ZIP is missing locally; this package includes source and run evidence but no exact-byte prediction artifact. Local, pilot, and hidden metrics are deliberately kept distinct. A single scored run does not establish a causal architecture effect or statistical significance.
