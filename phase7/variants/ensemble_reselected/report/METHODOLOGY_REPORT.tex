\section*{Research question}
After self-match removal, re-evaluate blend selection using valid candidate rankings. This variant checks whether a blend favored by earlier dev selection remains useful after the ranking contract changes.
\section*{Architecture and mechanism}
Row-normalized neural scores and lexical TF-IDF scores are blended, excluding self before choosing seven unique candidates. The reselected weights are an export-level choice, not a new trained backbone.

\section*{Limitations and next check}
Multiple blend choices on 118 dev queries can overfit; hidden scores should be reported separately. Local, pilot, and hidden metrics are deliberately kept distinct. A single scored run does not establish a causal architecture effect or statistical significance.
