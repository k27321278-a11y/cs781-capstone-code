# Phase 7: from lexical retrieval to corrected neural rankings

Each query must return **seven unique, eligible prior-case IDs**. The implementation therefore has two problems: rank legal relevance and satisfy the candidate-pool contract. The first [lexical fallback](variants/lexical_fallback_initial/README.md) used TF-IDF similarity without a trained retriever and scored 0.3680. Its exact submitted ZIP is not in the local archive. Later exports removed the query's own ID from candidates, backfilled missing slots, and checked uniqueness and pool membership. The [self-excluded lexical export](variants/lexical_excluded_self/README.md) scored 0.4017 and the [corrected fallback](variants/lexical_fallback_corrected/README.md) 0.4022. These are ranking/export corrections, not new language-model architectures; the earlier score is not directly a clean architecture baseline.

The neural experiments reused an in-house Phase 1 A0 language-model representation. The saved runner divides each query or candidate into four spaced 256-token windows, mean-pools token states per window, projects and normalizes them, then uses a late interaction: each query window finds its best candidate window before the window-level evidence is combined. This retains several distant pieces of a long case instead of forcing a single truncated prefix. Supervised training draws hard negatives from lexical retrieval. [Full fine-tuning](variants/full_corrected/README.md) updates about 110.3M parameters and scored 0.4064. [Partial fine-tuning](variants/partial_corrected/README.md) updates about 28.5M and scored 0.4028; [LoRMA](variants/lorma_corrected/README.md) updates about 1.18M and scored 0.3969. These parameter counts come from the saved GPU report. The ranking differences are small enough that one run per branch does not justify a universal statement about fine-tuning capacity.

The [distilled student](variants/kd_corrected/README.md) transfers a teacher's candidate ranking distribution to a smaller model; its saved report lists about 67.8M trainable student parameters and the corrected submission scored 0.4034. This tests whether the teacher's ranking behavior can be compressed, not whether the student has copied all legal reasoning. Two prediction-level blends combine row-normalized neural and lexical scores. The [reselected blend](variants/ensemble_reselected/README.md) scored 0.4017 and the [corrected model ensemble](variants/model_ensemble_corrected/README.md) scored 0.4064, tied to four decimals with full fine-tuning. These are ensembles of separately trained scorers, not additional backbones.

An important interpretation boundary: an earlier ensemble local-dev figure of 0.4158 predates the self-match correction; the saved correction report leaves the *corrected* ensemble dev metric unreported. We therefore report the finished Codabench 0.4064 without substituting the old local number.
