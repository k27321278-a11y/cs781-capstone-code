# Phase 1 report materials

`Phase1_LegalSpan_Report.md` is an evidence-based working report section for the best evidenced Phase 1 model. `Phase1_LegalSpan_Report.pdf` is its readable standalone rendering. This is **not** the final seven-phase capstone report. The official course template requires all seven phases within 10 counted pages, a public repository link, references, and a complete LLM Usage Declaration. The student must check and revise this draft against the course's LLM-use limits before submission.
